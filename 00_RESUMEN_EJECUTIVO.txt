PROBLEMA ORIGINAL:
─────────────────────────────────────────────────────────────────────────────
Cuando el usuario presiona el botón de emergencia en Android, solo se envía
SMS. Tú quería que la ubicación (lat/lon) se guardara en la BD para que el
admin pueda verla en el dashboard web.

✅ SOLUCIÓN IMPLEMENTADA:
─────────────────────────────────────────────────────────────────────────────

📱 ANDROID:
   Botón de emergencia presionado
   ↓
   Obtiene ubicación (lat/lon)
   ↓
   Envía HTTP POST al backend
   ↓
   Backend recibe y guarda en BD
   ↓
   Admin ve en dashboard web

FLUJO DE DATOS:
────────────────────────────────────────────────────────────────────────────────

👤 USUARIO
   ↓ presiona botón rojo
   
📱 ANDROID APP
   ├─ Obtiene ubicación
   ├─ Crea: EmergencyAlertRequest
   │  {
   │    "user_id": 5,
   │    "latitude": -17.8252,
   │    "longitude": -63.1687,
   │    "description": "Alerta...",
   │    "device_name": "Xiaomi"
   │  }
   └─ Envía HTTP POST
   
🌐 INTERNET
   ↓ POST /api/v1/emergency-alerts
   
🔧 BACKEND FASTAPI
   ├─ Valida datos (schema)
   ├─ Verifica usuario
   ├─ Crea registro en emergency_alerts
   └─ Retorna JSON response
   
💾 BASE DE DATOS
   INSERT INTO emergency_alerts VALUES (...)
   
👨‍💼 ADMIN
   └─ Ve en Angular dashboard

TABLA CREADA:
────────────────────────────────────────────────────────────────────────────────

TABLE: emergency_alerts
├─ id (int, PK, auto)
├─ user_id (int, FK → users.id)
├─ latitude (float)
├─ longitude (float)
├─ description (text, nullable)
├─ device_name (varchar, nullable)
├─ status (varchar, default='active')
├─ created_at (datetime)
└─ updated_at (datetime)

════════════════════════════════════════════════════════════════════════════════

ENDPOINTS DISPONIBLES:
────────────────────────────────────────────────────────────────────────────────

POST   /api/v1/emergency-alerts          → Crear alerta
GET    /api/v1/emergency-alerts          → Listar (paginado)
GET    /api/v1/emergency-alerts/{id}     → Detalle
PATCH  /api/v1/emergency-alerts/{id}     → Actualizar
DELETE /api/v1/emergency-alerts/{id}     → Eliminar
