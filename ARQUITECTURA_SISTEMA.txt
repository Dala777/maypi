FLUJO TEMPORAL (Step by Step)
══════════════════════════════════════════════════════════════════════════════════

1️⃣ Usuario abre la app
   └─ LoadData desde SharedPreferences (user_id)

2️⃣ Usuario presiona botón ROJO
   └─ executeEmergencyActions()
      ├─ startRecording() [5 segundos de audio]
      ├─ sendEmergencyLocationSMS() [SMS a contactos]
      ├─ sendEmergencyLocationToBackend() ← NUEVO
      │  └─ obtiene ubicación mediante FusedLocationProviderClient
      │  └─ crea EmergencyAlertRequest
      │  └─ RetrofitClient.apiService.sendEmergencyAlert(request)
      │     └─ POST HTTP a /api/v1/emergency-alerts
      └─ abrirCamara() [Foto]

3️⃣ Backend recibe POST
   └─ controllers/emergency_alert.py
      ├─ Valida schema (EmergencyAlertStore)
      ├─ Busca user en BD
      ├─ Crea nuevo registro EmergencyAlert
      └─ Retorna JSON response

4️⃣ Android recibe respuesta
   └─ Toast: "Alerta enviada al administrador"
   └─ Log: "Emergency alert sent successfully"

5️⃣ Admin abre Angular dashboard
   └─ EmergencyAlertsListComponent
      ├─ loadAlerts() → GET /api/v1/emergency-alerts
      └─ Visualiza tabla con nuevas alertas

6️⃣ Admin interactúa
   ├─ Ver ubicación en Google Maps
   ├─ Marcar como resuelto (PATCH)
   └─ Eliminar alerta (DELETE)

PERMISOS REQUERIDOS (Android)
══════════════════════════════════════════════════════════════════════════════════

AndroidManifest.xml:
├─ INTERNET (obligatorio para HTTP)
├─ ACCESS_FINE_LOCATION (ubicación precisa)
├─ ACCESS_COARSE_LOCATION (ubicación aproximada)
├─ SEND_SMS (enviar SMS)
├─ CALL_PHONE (realizar llamadas)
├─ CAMERA (tomar fotos)
└─ RECORD_AUDIO (grabar audio)

En tiempo de ejecución:
├─ Solicitar en requestLocationPermissions()
├─ Validar en checkLocationPermissions()
└─ Manejar resultado en onRequestPermissionsResult()
